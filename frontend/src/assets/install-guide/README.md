# 설치 안내 이미지

공식 사이트의 `/#/install` 페이지에서 사용하는 실제 화면 기반 안내 이미지입니다.

| 경로            | 용도                                                                            |
| --------------- | ------------------------------------------------------------------------------- |
| `source/`       | macOS 앱·iOS Simulator Safari·Android Emulator Chrome의 수정하지 않은 캡처 원본 |
| `highlighted/`  | 원본을 입력으로 이미지 생성 도구가 빨간 번호·박스·화살표를 추가한 PNG           |
| `web/`          | 강조본을 같은 해상도의 WebP(품질 90)로 변환한 페이지용 파일                     |
| `manifest.json` | 캡처 환경, 파일 해시, 생성 프롬프트, 원본 출처                                  |

페이지는 `web/`만 import합니다. 원본과 강조 PNG는 배포 번들에 포함하지 않습니다.

## 이미지 교체하기

1. 해당 OS의 기본 브라우저에서 실제 화면을 캡처하고 `source/`에 보관합니다. 연결 코드·QR처럼 유효한 인증 정보가 들어간 화면은 사용하지 않습니다.
2. 원본을 확인한 뒤 이미지 생성 도구로 클릭할 위치만 강조합니다. 원래 UI·문구·배경을 유지하고 결과를 `highlighted/`에 저장합니다.
3. 강조 위치와 문구를 원본과 비교합니다. 확인한 강조본을 WebP로 변환해 `web/`에 저장합니다. 변환 과정에서는 번호나 도형을 그리지 않습니다.
4. `manifest.json`의 출처·프롬프트·해시를 갱신하고, `../../features/app-install/install-guide-images.ts`의 단계 설명과 이미지 크기를 맞춥니다.

## 캡처 범위

- iOS: Safari 메뉴부터 홈 화면 아이콘까지 6개 화면. 중복 설치를 피하려고 추가 확인 화면에서 취소한 뒤 이미 설치된 실제 아이콘을 캡처했습니다.
- Android: Chrome 메뉴, 홈 화면에 추가 메뉴, 설치 확인 대화상자 3개 화면. 홈 화면 아이콘 캡처는 포함하지 않습니다.
- 공통 설정: PC의 QR 생성 위치, PWA 연결 코드 입력, 알림 설정 시작과 iPhone 권한 요청 화면. 알림 설정 2장은 같은 시뮬레이터에서 앞서 촬영한 실제 화면을 재사용했습니다.
