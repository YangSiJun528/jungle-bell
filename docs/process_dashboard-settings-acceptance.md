# 대시보드 설정·내비게이션 개선 검증 기준

이 문서는 2026-08-12 대시보드 후속 개선 작업의 임시 추적 문서다. 아래 기준을
모두 구현하고 v2-test 배포 검증까지 통과한 뒤 저장소에서 삭제한다. 요구사항과
완료 과정은 Git 이력에만 남긴다.

## 구현 원칙

- [x] 배포 전 기존 서비스의 사용자 동작과 저장 계약을 Git 이력에서 확인하고,
      누락 없이 현재 구조에 옮긴다.
- [x] shadcn/ui에 있는 Sidebar, Tabs, Switch, Calendar, Dialog·Popover 등의
      컴포넌트를 우선 사용하고 동일 기능을 자체 구현하지 않는다.
- [x] 웹·PWA·Tauri의 기능 경계와 Tauri 최소 권한 원칙을 유지한다.

## 내비게이션과 사이드바

- [x] 사이드바의 `오늘`을 `홈`, `오늘의 급식`을 `식단`으로 변경한다.
- [x] 대시보드 사이드바는 저장소의 shadcn Sidebar 합성 컴포넌트를 사용한다.
- [x] 잘못 추가한 임의 폭 조절 range와 관련 브라우저 저장 코드를 제거한다.
- [x] shadcn Sidebar가 제공하는 표준 접기·펼치기 및 모바일 동작으로 교체하고,
      포인터와 키보드에서 모두 조작할 수 있게 한다.

## 설정

- [x] 설정을 의미가 분명한 여러 탭으로 나눈다.
- [x] 알림 설정에는 배포 전 기존 서비스의 전체 알림 여부, 시간대별 알림,
      급식 알림 등 서버 공유 항목을 복원한다.
- [x] 서버 공유 알림 설정은 PC와 연결된 휴대폰에서 같은 값을 읽고 수정한다.
- [x] 서비스 설정에는 기존 서비스 기준으로 사용자 데이터 수집, 로그 폴더 열기,
      디버그 모드, 자동 업데이트, 자동 시작 등 해당 플랫폼에서 지원하는 항목을
      제공한다.
- [x] 기기 로컬 설정과 서버 공유 설정을 섞지 않고, 지원하지 않는 웹 표면에는
      데스크톱 전용 조작을 노출하지 않는다.
- [x] 저장 실패·인증 필요·지원하지 않는 환경을 사용자가 구분할 수 있게 표시한다.

## 홈 D-Day

- [x] 배포 전 기존 서비스의 D-Day 정보를 현재 홈에 복원한다.
- [x] D-Day를 클릭하면 정확한 날짜와 월/일 형태의 시각 표현을 함께 확인할 수 있다.
- [x] 데이터 없음, 시작 전, 진행 중, 종료 상태를 기존 서비스 계약에 맞게 처리한다.

## 캘린더 의존성

- [x] 현재 shadcn Calendar와 하위 라이브러리의 역할을 공식 문서와 로컬 구현으로
      확인한다.
- [x] 별도 라이브러리가 중복·노후 구현이면 제거하고 shadcn Calendar로 통일한다.
- [x] shadcn Calendar 자체가 해당 라이브러리를 기반으로 한다면 병렬 자체 구현을
      추가하지 않고 의존성을 유지하는 이유를 장기 참고 문서에 기록한다.
- [x] 급식 기록 캘린더의 월 이동, 선택, 비활성 날짜와 접근성 동작을 유지한다.

## 완료 조건

- [x] 관련 프런트엔드·서버·Rust 테스트를 추가하고 통과시킨다.
- [x] `npm run verify`와 React Doctor 변경 범위 검사가 통과하고 진단 점수가
      회귀하지 않는다.
- [x] 실제 Tauri 논리 크기와 웹 반응형 크기에서 홈·설정·사이드바·급식 캘린더를
      캡처해 잘림, 겹침과 비정상 동작이 없음을 확인한다.
- [x] v2-test D1 마이그레이션과 Jobs·Worker 재배포 뒤 작업 주기, 주요 API와
      대시보드 경로 smoke test가 통과한다.
- [x] 모든 항목을 확인한 후 이 문서를 삭제하는 후속 커밋을 만든다.
