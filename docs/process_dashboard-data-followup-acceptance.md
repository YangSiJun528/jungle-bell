# 대시보드 데이터 후속 개선 인수 기준

문서 유형: process.

이 문서는 급식 기록·세탁 상태·출석 및 설정 후속 개선의 임시 인수 기준이다.
각 항목은 자동 테스트와 실제 데이터로 검증한다. 완료 후 작업 트리에서는 제거하되
Git 이력에는 남긴다. 외부 상태 때문에 완료할 수 없는 항목은 원인과 확인 증거를
기록한 뒤 나머지 작업을 계속한다.

## 기능 인수 기준

- [ ] 지난 급식 기록의 수동 `이전 기록 더 불러오기` 동작을 제거하고, 사용자가
  달력을 다른 달로 이동할 때 해당 달에 필요한 기록을 자동으로 조회한다.
- [ ] `7월 2주차 식단표`를 포함한 과거 주간 식단표의 원본·D1·R2·OCI 수집 경로를
  확인하고, 실제 보관 데이터가 있으면 지난 기록 화면에 표시한다. 원본 자체가
  없으면 확인한 저장소와 조회 결과를 기록한다.
- [ ] 홈의 `남성 가능`·`여성 가능` 수치가 공개 세탁 상태에서 올바르게 계산되고
  실제 v2-test 응답과 화면에서 일치한다.
- [ ] 출석 페이지에도 현재 선택 기수의 D-Day 카드가 표시된다.
- [ ] 연결된 모바일 조회가 성공했지만 목록이 비어 있으면 오류가 아니라 정상적인
  미등록 상태로 안내한다. 인증·네트워크 실패와 빈 응답은 구분한다.
- [ ] 워시타워 상태 카드 상단 범례의 경고 뱃지는 아이콘 없이 표시한다. 실제 경고
  기기 셀의 접근 가능한 경고 표시는 유지한다.
- [ ] 동일한 수동 갱신·빈 상태·오류 상태에 쓰는 사용자 문구를 화면 전체에서
  일관되게 정리한다.
- [ ] 데스크톱 설정에서 LMS 기수를 선택할 수 있고, 선택값은 검증된 로컬 앱 설정에
  저장되어 checker와 출석·D-Day 계산에 함께 적용된다.

## 검증 및 배포 기준

- [ ] 프런트엔드·서버·Rust 테스트, 타입 검사, 앱과 Jobs 빌드가 통과한다.
- [ ] React Doctor 점수가 작업 전 기준인 77점보다 낮아지지 않는다.
- [ ] 실제 Tauri 창 크기에서 급식 기록·홈·출석·세탁·설정 화면을 캡처해 잘림과
  상태 오류가 없음을 확인한다.
- [ ] v2-test Worker와 필요한 OCI Jobs를 배포하고 공개 API·정적 화면·수집 로그를
  검증한다.
- [ ] 프로덕션 설정·인증·데이터 저장소가 유효하면 같은 검증 절차로 배포한다.
  유효하지 않으면 배포를 강행하지 않고 차단 원인과 확인 증거를 기록한다.
- [ ] 임시 캡처 코드와 이 문서를 제거하고 최종 변경을 커밋한다.
