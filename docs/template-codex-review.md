# Codex 검토 인계 템플릿

> 문서 유형: 참조(reference) · 선택적 실행용 사본 템플릿

메인은 구현 자체 검증과 필요한 조합 확인·QA 결과를 모은 뒤 이 정보를 Reviewer에게 전달합니다.
작은 작업은 같은 필드를 한 메시지에 담아도 됩니다. 파일이 필요하면 저장소 밖에 복사하고,
원본은 빈 템플릿으로 유지합니다. 실행 상태·보고서·로그·캡처는 커밋하지 않습니다.
호출 순서와 완료 판정은 작업 저장소의 `docs/guide-codex-main.md`를 따릅니다.

## 완료 조건별 검증 결과

같은 실행으로 확인한 조건은 한 행에 묶어도 됩니다. 명령은 실행 디렉터리와 함께 적고,
실제 결과에는 종료 코드·실패 수 또는 관찰한 동작을 적습니다. 증거는 로그·캡처의 절대 경로나
CI 링크로 연결하며, 메시지에 결과를 직접 담았다면 그 위치를 적습니다.
미실행·근거 부족은 미검증으로 남깁니다. 코드 검토에서 결함을 찾지 못한 사실은 실행 검증 결과와 구분합니다.

## Reviewer에게 요청할 판정

원래 요구사항과 대상 변경을 직접 대조하고, 완료 조건별 판정·근거·남은 문제를 반환합니다.
확인 가능한 실행 증거는 재사용하고 부족한 부분만 검사합니다. 필수 조건의 실패·미검증이나
해결되지 않은 결함이 남으면 완료로 판정하지 않습니다.
