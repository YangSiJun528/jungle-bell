# 대시보드 UI 개선 검증 기준

이 문서는 2026-08-12 대시보드 UI 개선 작업의 임시 추적 문서다. 아래 기준을
모두 구현하고 v2-test 배포 검증까지 통과한 뒤 저장소에서 삭제한다. 요구사항과
완료 과정은 Git 이력에만 남긴다.

## 워시타워

- [ ] 정상 작동 상태에서 상태명 옆의 `예상` 표기를 제거한다.
- [ ] 보정 종료 시각이 지났지만 LG ThinQ API의 완료 확인을 기다리는 상태만 별도
      정보 아이콘으로 설명한다. 설명은 "예상 시간으론 완료인데 LG ThinQ API에서
      확실한 확인을 기다리는 중"이라는 의미를 명확히 전달한다.
- [ ] 완료 확인 대기 상태의 진행 색상은 노란색이 아니라 가득 찬 초록색을 사용한다.
- [ ] 경고 상태는 채도가 낮은 연한 빨간색 토큰을 사용한다. 성별 색상과 구분되는
      뱃지를 추가하고, 문구 대신 삼각형 안의 느낌표 아이콘으로 표시한다.
- [ ] `전체 NN분` 표기를 `총 NN분`으로 변경한다.
- [ ] 정보 아이콘의 설명 팝오버는 한국어 단어 단위로 자연스럽게 줄바꿈한다.
- [ ] 상태 문구는 짧고 직관적인 표현을 사용한다.
  - `바로 사용할 수 있어요` → `사용 가능`
  - `기기 확인이 필요해요` → `확인 필요`
  - `약 NN분 남음` → `NN분`
- [ ] 남성·여성·공용 색상은 현재 성별 뱃지 색상을 단일 토큰 원본으로 삼아 카드,
      진행 표시와 관련 UI에 일관되게 적용한다.

## 급식

- [ ] 급식이나 메뉴가 아직 게시되지 않은 상태에서는 같은 의미의 문구와 중첩 박스를
      반복하지 않고 하나의 빈 상태만 표시한다.
- [ ] 지난 급식 기록을 캘린더와 선택 기록이 읽기 쉬운 반응형 레이아웃으로 재배치한다.
- [ ] 캘린더 상단 이전·다음 버튼과 월 제목이 한 줄에서 정렬되고 잘리거나 벌어지지
      않는다.
- [ ] 선택한 식단 카드와 주간 식단표가 화면 폭에 맞게 배치되며 내용과 이미지가
      읽기 쉬워야 한다.

## 탐색과 알림

- [ ] 사이드바 폭 조절 슬라이더를 포인터와 키보드로 실제 조작할 수 있다.
- [ ] 웹 화면에서는 앱 전용 기능이 빠진 자리에 생기는 사이드바 하단 가로선을
      표시하지 않는다.
- [ ] 알림을 본 알림으로 처리할 수 있다.
- [ ] 본 알림은 기본 알림 목록에서 즉시 숨기고 별도 세부 탭에서 다시 확인할 수 있다.

## 완료 조건

- [ ] 관련 단위·컴포넌트 테스트가 통과한다.
- [ ] `npm run verify`와 React Doctor 변경 범위 검사가 통과하고 진단 점수가 회귀하지
      않는다.
- [ ] 실제 Tauri 논리 크기와 웹 반응형 크기로 전체 화면을 캡처해 잘림, 겹침,
      비정상 줄바꿈이 없음을 확인한다.
- [ ] v2-test Worker에 재배포한 뒤 주요 API와 대시보드 경로 smoke test가 통과한다.
- [ ] 모든 항목을 확인한 후 이 문서를 삭제하는 후속 커밋을 만든다.
