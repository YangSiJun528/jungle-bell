# 릴리스 UI·데이터 정리 인수 기준

문서 유형: process.

이 문서는 릴리스 UI·데이터 정리 작업의 임시 인수 기준이다. 모든 항목을 검증한
뒤 작업 트리에서 제거하되 Git 이력에는 남긴다.

## 범위

- 하위 호환성은 제공하지 않는다. 아직 실제 사용자가 없으므로 현재 계약과 저장
  구조를 직접 정리한다.
- 기존 작업 트리의 계정 인증·개인 세탁·사이드바 변경을 보존한다.

## 인수 기준

- [ ] 급식 알림 설정과 서버 계약·저장소·Jobs에서 조식 옵션이 완전히 제거되고
  중식·석식만 제공된다.
- [ ] 디버그 모드를 켤 때 로그 증가와 특별 목적 외 사용 금지를 설명하는 확인
  다이얼로그가 나오며, 명시적으로 확인해야만 활성화된다.
- [ ] PC 연결 정보 초기화는 영향 범위를 설명하는 확인 다이얼로그에서 명시적으로
  확인해야만 실행된다.
- [ ] macOS 트레이의 정상 상태는 시스템 테마가 자동으로 대비를 정하는 단색
  template 아이콘을 사용하고, 확인·조치가 필요한 상태에서만 상태색을 사용한다.
- [ ] 사용자에게 보이는 수동 갱신 동작의 문구가 `새로고침`으로 통일된다.
- [ ] 선택한 주 급식표에서는 변경될 수 있는 원본 KakaoTalk 게시물 링크를
  제공하지 않는다. 날짜별 급식 기록의 출처 링크 계약은 유지한다.
- [ ] 실제 DB 또는 로컬 수집기 데이터로 확인 가능한 이전 식단이 지난 급식 기록에
  표시되며, 임의의 샘플 데이터로 대체하지 않는다.
- [ ] 사이드바 최상단 Jungle Bell 브랜드 영역은 hover·active 하이라이트를 만들지
  않는다.

## 완료 검증

- [ ] 프런트엔드·서버·Rust 테스트와 타입 검사, 프로덕션 앱 빌드가 통과한다.
- [ ] React Doctor 점수가 작업 전 기준보다 낮아지지 않는다.
- [ ] 실제 Tauri 크기에서 설정·급식·사이드바·홈 화면을 캡처해 잘림과 상호작용
  오류가 없음을 확인한다.
- [ ] 임시 캡처 코드와 이 문서를 제거하고 최종 변경을 커밋한다.
